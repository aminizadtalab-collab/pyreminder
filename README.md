## ✨ Features

- 🪟 **Glassmorphism Aesthetic:** Translucent dark-mode interface with smooth gradients and modern styling.
- 🔔 **Interactive Popup Reminders:** Desktop popup with actions like **Done**, **Snooze (10 mins)**, and **Dismiss**.
- ⏰ **Advanced Recurrence:** Supports Daily, Weekly, Monthly, Workdays (Sat–Wed), and Hourly intervals.
- 🎯 **Skill & Task Tracking:** Manage both daily routines and long-term skills with priority levels (Urgent, High, Normal, Low).
- 📊 **Gamified Analytics:** Built-in XP point system and daily completion progress tracker.
- 📥 **System Tray Integration:** Runs silently in the background without cluttering your workspace.
- 🚀 **Zero Pip Headache:** Optimized to use standard system packages without triggering PEP 668 errors.
